# Björn Glück

Security lead. I work on IAM and governance, and lately on how AI agents get access to things. I still build, mostly at home on a desk rack of Raspberry Pis. Also into 3D printing and anything space.

My rule: move faster, but not without the basics. If auth, logs and validation aren't in the requirements, it isn't ready to ship.

## What I'm building

- [PiHerder](https://github.com/bjorngluck/piherder): open source fleet management for Raspberry Pi and homelab hosts. Backups, patching, Docker, and agent access with scoped tokens and an audit log. MIT. [Docs](https://piherder-docs.hacknow.info)
- [piherder-ha](https://github.com/bjorngluck/piherder-ha): Home Assistant integration for PiHerder.
- [piherder-mcp](https://github.com/bjorngluck/piherder-mcp): lets AI agents work with PiHerder through its API.
- [hailo-llm-addon](https://github.com/bjorngluck/hailo-llm-addon): Home Assistant add-on for running local LLMs on a Hailo-10H with Ollama.
- [raspberry-pi-oled-monitor](https://github.com/bjorngluck/raspberry-pi-oled-monitor): a small OLED display that shows load, memory, disk and containers on a Pi.
